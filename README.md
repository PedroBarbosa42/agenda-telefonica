# Agenda-telefonica

Agenda telefônica simples como aplicação monolítica, usando Flask e templates Jinja2 em um único projeto, sem separação entre front-end e back-end. O sistema permite cadastrar contatos (nome, telefone e e-mail), listar todos os contatos e consultar os detalhes de cada um. A persistência foi feita em um arquivo contatos.json, lido e gravado a cada requisição.
